ThingSpeak field mapping

Expected channel schema

Field 1Access result — 1 granted, 0 denied
Field 2Total scan count
Field 3Denied scan count
StatusOptional UID text such as RFID_UID:A3:7F:12:BC

ThingSpeak fields are numeric. Store a hexadecimal UID in the feed entry's status text if you need to preserve the full UID exactly. ThingSpeak does not store the card registry in this application.

Integration checklist

Required to enable real device reporting

  • 01
    Configure device token

    Set DEVICE_API_TOKEN in server environment and firmware.

  • 02
    Send heartbeat

    POST to /api/device/heartbeat every 30 seconds.

  • 03
    Submit each UID

    POST to /api/device/scan and use its result for the relay decision.

  • 04
    Fail securely

    If backend is unavailable, keep the locker locked.

ImportantThingSpeak alone is not a secure real-time authorization service. This app uses a server-side card registry and authenticated device API for access decisions; ThingSpeak remains the cloud analytics feed.
